# トラテン 登山口アクセス V6

全国主要登山口 **228地点** を固定アクセスDBに収録。

## V6の主な変更

- V5の224地点から228地点へ拡張
- `折立登山口` を `折立` の別名として明示対応
- `坊村 武奈ヶ岳登山口` を `葛川坊村` の別名として明示対応
- 新中の湯登山口／上高地焼岳登山口／えびの高原／大雪高原温泉を追加
- 未登録地点は従来どおり **「アクセス情報なし」** を常時表示
- `audit_access_coverage.py` で app.js と突合し、未対応だけを `ACCESS_MISSING_ONLY.txt` に出力

## 適用

```bash
完全パッケージには適用済みです。追加のパッチ作業は不要です。
```

適用先に `app.js` がある場合は監査スクリプトも実行できます。

```bash
python audit_access_coverage.py app.js --access-data access-data.js
```

> 林道・バス・ロープウェイ・マイカー規制・火山規制は変動します。画面では公式情報の確認を促す前提です。
