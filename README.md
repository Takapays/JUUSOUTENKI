# 縦走山行判断ツール V1.5.3

## V1.2
- 登山道検索を廃止
- 距離・累積標高・コースタイム計算を廃止
- 「この山のルート候補を読み込む」は維持（内蔵候補を即時表示）
- 登山口・山小屋・・峠・山頂・下山口を手動選択
- 各地点の**通過日と通過時刻を手動入力**
- 「この計画を分析開始」で即気象分析

## Render
Build Command は以前のV5.5系のままでも動くよう `build_trail_graphs.py` を残していますが、V1.0では登山道データを使いません。推奨は:

`pip install -r requirements.txt`

Start Command:

`gunicorn --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120 server:app`


### V1.2 追加
- 候補読込後、登山口・山頂・山小屋・下山口の4行を最初から表示
- 山小屋・で「ここに泊まる」チェックを表示
- 宿泊地点を1泊目・2泊目…として自動分析
- 日の入り・日の出・夜間最低気温・体感温度・風・突風・降水・雲量・ガス/霧リスクを表示
- 天の川の見えやすさ目安（雲量・降水・視程・湿度・月明かり）と夜間ベスト時刻を表示


### V1.5 追加
- 全体を明るいライトUIへ変更
- 日付・時刻入力のカレンダー/時計アイコンを高コントラスト化
- 途中の通過ポイント日時を変更すると、後続ポイントを同じ差分だけ自動で前後へ移動
- 日付をまたぐ変更にも対応


### V1.6 追加
- 宿泊分析の「日の入り / 天の川 / 日の出」を3枚の判定カードとして横並び表示
- 日の入り・日の出も天の川と同じ強調背景で見やすく表示

### V1.6 追加
- スマホ表示では通過日と通過時刻を別段に配置
- 日付/時刻入力の最小幅を解除し、画面幅からはみ出さないよう調整


### V1.5.3 追加
- スマホで通過日と通過時刻を完全に別行表示
- 日付/時刻入力をスマホ幅100%に固定し、重なりを解消
- CSS/JSのキャッシュバージョンを更新

## V1.5 変更
- 気象モデルは JMA / ECMWF / GFS / ICON の4モデルに整理
- 初期ポイントは「登山口 / 山頂 / 山小屋・避難小屋 / 下山口」の4行
- 乗越・峠・分岐は初期表示・種類選択から除外
- 燕岳を選ぶと大天井岳・常念岳・槍ヶ岳など、同じ縦走山域の主要地点も候補表示
- 槍・穂高エリアも槍ヶ岳・南岳・北穂高岳・涸沢岳・奥穂高岳などを横断候補化


## V1.5.1
- 画面に予報期間の目安を表示（0〜4日 / 5〜7日 / 8〜15日 / 16日以降）
- 入力した通過日のうち最も遠い日付に応じて、利用できるモデルの目安を自動表示


## V1.6
- 「＋ 地点を追加」を「この計画を分析開始」の直上へ移動
- 新規追加ポイントの通過日時を、最後のポイントの日時 +1時間で自動設定
- 23時台からの追加では日付も自動で翌日に繰り上げ


## V1.6
分析結果に気温、風速・突風、降水量、雲量の地点別グラフとA-Eリスク帯を追加。スマホでは横スクロール表示。
